# Surgical Robot Control

腹腔镜手术机器人实验项目。当前主要在进行 Python 控制接口对接、机械臂状态读取，以及 1 号臂和 3 号臂的基础运动测试。

## 已完成的工作

- 接入 `ULaparRobotControl`，编写机器人连接、断开及状态读取流程。
- 读取 1～4 号机械臂的工具位姿、关节状态，并读取柔性段位姿。
- 编写工具位姿解析：将 12 维数据转换为位置、旋转矩阵、齐次变换矩阵和 XYZ 欧拉角，并进行基本数据检查。
- 编写 1 号臂与 3 号臂的同步运动函数：位置采用线性插值，姿态采用四元数 SLERP。
- 编写测试脚本，包含两臂小幅平移、绕自身 Z 轴旋转等基础运动指令。
- 添加带时间戳的状态日志记录，以及测试结束时的清理流程。

> 以上表示代码已编写；具体功能是否通过现场验证，以实际测试记录为准。

## 运行说明

运行环境需要安装 `numpy`、`scipy`，并配置实验设备提供的底层接口模块 `u_lapar_control`（该模块未包含在本仓库中）。

在项目根目录执行：

```bash
python src/test.py
```

**注意：** `test.py` 包含真实机械臂运动指令。运行前需确认设备连接、工作模式、坐标系和目标位姿，并确保现场环境安全；不要未经确认直接运行。
