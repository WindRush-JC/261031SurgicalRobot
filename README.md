# Surgical Robot Control

面向腹腔镜手术机器人实验的 Python 控制与状态读取示例。当前仓库主要用于连接机器人控制接口、读取机械臂状态、解析工具位姿，并验证双机械臂的基础笛卡尔空间运动。

> **项目状态：实验 / 开发中。**
> 本仓库包含上层 Python 示例代码和实验笔记；底层控制接口模块 `u_lapar_control` 由外部环境提供，未包含在本仓库中。运行前必须确认机器人型号、接口版本、坐标系定义和安全限制。

## 当前实现

- 通过 `ULaparRobotControl` 建立机器人控制连接，并等待实时工具位姿数据。
- 读取 1～4 号机械臂的工具位姿、关节状态和柔性段位姿。
- 校验工具位姿数据的维度、有限数值、旋转矩阵正交性及行列式。
- 将 12 维工具位姿解析为位置、3×3 旋转矩阵、4×4 齐次变换矩阵和 XYZ 欧拉角。
- 对 1 号臂和 3 号臂进行同步目标位姿插值：位置采用线性插值，姿态采用四元数 SLERP。
- 记录带时间戳的状态日志；测试脚本结束时尝试清除跟踪指令、锁定机械臂并断开连接。

## 环境与依赖

代码使用 Python，主要依赖：

- NumPy：数组处理、矩阵运算；
- SciPy：旋转矩阵、欧拉角与四元数球面线性插值（SLERP）；
- `u_lapar_control`：机器人底层通信与控制接口，需从设备配套 SDK 或实验环境单独获取。

建议使用与机器人控制 SDK 兼容的 Python 版本，并在独立虚拟环境中安装依赖：

```bash
python -m venv .venv
```

Windows PowerShell：

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install numpy scipy
```

Linux：

```bash
source .venv/bin/activate
python -m pip install numpy scipy
```

随后还需要按底层 SDK 的要求配置 `u_lapar_control` 模块及其依赖。该模块不在本仓库中，因此仅安装 NumPy 和 SciPy 并不足以运行机器人控制脚本。

## 运行前检查

1. 在机器人控制器和运行主机之间建立符合实验要求的网络连接。
2. 确认 `u_lapar_control` 已正确安装，并且其版本与机器人控制器匹配。
3. 核对控制器 IP、端口、工作模式、机械臂编号及接口权限。当前代码调用 `ULaparRobotControl()` 默认配置；底层接口笔记中记录的默认地址为 `172.31.0.151:16010`，实际值应以现场配置为准。
4. 确认工具位姿的坐标系、单位、旋转矩阵排列顺序，以及目标位姿的参考坐标系。
5. 确保机器人处于可安全测试的状态：工作空间清空、人员远离运动范围，并由熟悉设备急停和恢复流程的人员现场监护。

## 运行示例

在项目根目录执行：

```bash
python src/test.py
```

当前测试脚本会尝试：

1. 创建控制对象并连接机器人；
2. 等待 1 号臂工具位姿数据；
3. 读取四个机械臂的工具位姿和关节状态，并读取 1 号臂柔性段位姿；
4. 锁定、解锁机械臂并切换到 `WORKMODE_AUTO_SURGICAL`；
5. 使 1 号臂和 3 号臂分别进行小幅位置移动，并测试两臂绕自身 Z 轴旋转；
6. 在 `finally` 清理流程中尝试清除跟踪、锁定全部机械臂并断开连接。

日志写入 `data/data_时间戳.log`。目录会在运行时自动创建；`data/` 下的日志文件不会提交到 Git。

> **安全警告：** `src/test.py` 不只是离线测试脚本，它会向真实机器人发送运动指令。首次运行前请先审查代码和目标位姿，确认工作模式、坐标系、运动范围、速度及夹爪状态；先在仿真或安全测试条件下验证。不要在不了解接口语义时直接运行，也不要将示例中的运动增量视为通用安全参数。

## 关键数据约定（以当前代码为准）

### 工具位姿

`get_current_toolpose(arm_id)` 当前按 12 维数组处理：

```text
[x, y, z,
 r11, r12, r13,
 r21, r22, r23,
 r31, r32, r33]
```

代码将前三项作为位置，后九项按行展开并重塑为 3×3 旋转矩阵。位置单位、坐标系归属及旋转矩阵表达约定仍需结合设备 SDK 文档和现场标定结果确认。

### 关节状态

当前笔记记录关节数组为 11 维，最后一维用作夹爪状态。各关节的具体含义、单位、范围及顺序仍需以底层接口定义为准。

### 双臂插值运动

`move_dual_to_pose()` 面向 1 号臂和 3 号臂：

- 位置：线性插值；
- 姿态：四元数 SLERP；
- 两臂使用相同插值步数；
- 当前代码设置基准位置步长为 0.25 mm，发送周期为 0.05 s，基准旋转步长为 1°；实际执行效果及安全性必须在设备条件下验证。
